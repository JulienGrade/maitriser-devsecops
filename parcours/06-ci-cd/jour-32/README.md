# Jour 32 — Gouvernance du projet DevSecOps

## Objectif

Relier backlog, dépôt, pipeline, artefact et décision de livraison.

## Activité

Définissez une politique de branches, un modèle de pull request, des propriétaires de code et des critères de réussite. Reliez une user story à un commit et à un déploiement. Ajoutez une procédure de dérogation comportant propriétaire, justification, compensation et expiration.

## Points de contrôle

Les droits suivent le moindre privilège. Les branches principales sont protégées. Les preuves de test sont conservées selon une durée définie. Les dérogations expirent réellement.
